# Balle Bot — landing page

Exercício de landing page para apresentação do Balle Bot, inspirado na Comunidade Ballerini. Este repositório contém a página; não implementa o bot de Discord descrito no texto.

## Tecnologias

- HTML
- CSS

## Funcionalidades e utilização

Explore a apresentação. O botão de adicionar o bot não representa uma implementação de backend neste repositório.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/Lading-page-BELLEBOT.git
cd Lading-page-BELLEBOT
python -m http.server 8000 --directory "."
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
